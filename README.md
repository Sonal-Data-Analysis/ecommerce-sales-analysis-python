# Ecommerce Sales Analysis Using Python

## Project Overview
This project focuses on analyzing ecommerce sales and profit data using Python. The goal is to understand sales performance, identify profitable product categories, and compare business performance across customer segments.

## Objectives
- Analyze monthly sales and profit trends.
- Identify top-performing product categories and sub-categories.
- Compare sales and profit across customer segments.
- Calculate profit margins.
- Present business data through interactive visualizations.

## Tools and Technologies
- **Python** – Data analysis
- **Pandas** – Data cleaning and manipulation
- **Plotly Express** – Interactive data visualization
- **Jupyter Notebook** – Writing and running Python code

## Dataset
The project uses the Sample Superstore dataset, which contains order, product, sales, profit, shipping, and customer information.

The notebook output indicates that the dataset contains 9,994 rows and 21 columns.

## Project Workflow
1. Load the dataset using Pandas.
2. Explore the dataset using `head()`, `info()`, `describe()`, and missing-value checks.
3. Convert date columns into datetime format.
4. Group data to calculate total sales and profit.
5. Analyze performance by month, category, sub-category, and customer segment.
6. Create interactive charts using Plotly Express.
7. Calculate profit margin to compare segment performance.

## Key Analysis Areas
- Monthly Sales Trend
- Sales by Category
- Sales by Sub-Category
- Monthly Profit Trend
- Profit by Category
- Profit by Sub-Category
- Sales and Profit by Customer Segment
- Profit Margin by Customer Segment

## How to Run the Project

### 1. Install the required libraries
```bash
pip install pandas plotly jupyter
```

### 2. Add the dataset
Place `Sample - Superstore.csv` in the same folder as the Jupyter Notebook.

### 3. Open Jupyter Notebook
```bash
jupyter notebook
```

Open the project notebook and run the cells in order.
